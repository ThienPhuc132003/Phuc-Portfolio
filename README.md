# Phúc Portfolio

Portfolio song ngữ Việt–Anh về UX/UI và sản phẩm số, triển khai trên GitHub Pages.

## Chạy local

```bash
python -m http.server 8765
```

Truy cập http://localhost:8765/. Nội dung và giao diện nằm trong `index.html`, `style.css` và `script.js`. Hai bản PDF được lưu tại `portfolio-vi.pdf` và `portfolio-en.pdf`; ảnh dự án nằm trong `assets/`.
