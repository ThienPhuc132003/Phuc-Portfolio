CASE STUDY / 03

GiaSuVLU

Making learning easier to find.

A team graduation project exploring a tutoring platform for learners and tutors.

MY ROLE

UX/UI · frontend · API integration

VIEW SOURCE CODE ↗

01 / CONTEXT

The context

The team explored tutor registration, tutor search and learner assessment as parts of a platform connecting Van Lang students with learners. The project used React.js for the frontend and Node.js for the backend.

02 / CONTRIBUTION

How I contributed

I decided the interface and UX flows, developed the frontend and connected APIs. My teammate mainly built the database and APIs.

03 / DESIGN

Designing the interface flows

The project brought together the learner and tutor sides of the experience. I shaped the screens and their connections, then integrated the frontend with APIs provided by my teammate.

04 / STATUS

Where it stands

School-email sign-in with Microsoft worked during the project. Zoom and bank/MoMo payments reached API tests and demos only, with legal and cost requirements preventing completion. The backend is currently unavailable; a rework is planned.
